# kinetic-gain-examples-gallery

Examples gallery for the [Kinetic Gain Protocol Suite](https://suite.kineticgain.com) — pick a spec from the sidebar, see its canonical example rendered with JSON syntax highlighting + landing-page / repo / visualizer cross-links.

Live at **[examples.kineticgain.com](https://examples.kineticgain.com)**.

React 19 + TypeScript + Tailwind 4, client-side only, all 10 example documents bundled inline.

## Local dev

```bash
npm install
npm run dev
npm run typecheck
npm run build
```
